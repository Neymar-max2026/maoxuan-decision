# 毛选决策方法论 · maoxuan-decision

> 把《毛泽东选集》中的决策方法，提炼成 166 张可检索的「方法卡」，
> 封装为一个 AI Agent Skill：**识别场景 → 检索方法卡 → 结构化分析 → 输出决策建议**。

当你面对两难、多选、犹豫不决，或需要在创业方向、职业选择、投资、谈判、
团队方向等重大取舍上做分析时，这个 skill 会按一套固定的四步流程带你走完。

---

## 它解决什么问题

普通 AI 给决策建议，容易变成「正反两面都说说」的空泛套话。
本 skill 的做法是：**先判定你面临的是哪一类决策，再调用对应的方法论卡片，
按卡片的决策算法逐步向你提问，最后由你的实际信息得出建议。**

方法来源于《毛泽东选集》的 12 类决策场景，但不是让你"学毛选"，
而是把其中的决策算法提取成可直接施行的步骤。

---

## 12 个决策场景

| # | 场景 | 典型纠结 |
|---|---|---|
| 1 | 认知判断 | 我对这件事的判断到底对不对？现在掌握的情况可信吗？ |
| 2 | 时机判断 | 要不要现在动手？是不是该再等一等？ |
| 3 | 力量配置 | 钱/人/时间该怎么分配？要不要 all in 一个方向？ |
| 4 | 强弱转化 | 我明显处于劣势，还能不能做？怎么避免被强者拖垮？ |
| 5 | 矛盾分析 | 问题千头万绪，先抓哪一个？几方的利益冲突怎么理？ |
| 6 | 组织决策 | 团队意见不统一怎么办？该民主讨论还是我来拍板？ |
| 7 | 调查研究 | 信息不够，要不要先调研？调研到什么程度才够？ |
| 8 | 路线选择 | 两条路线选哪条？哪些事先做、哪些事不做？ |
| 9 | 谈判博弈 | 谈判该让多少？这个合作方该联合还是该防？ |
| 10 | 执行方法 | 定了之后怎么推进？执行走样了怎么纠？ |
| 11 | 战略定力 | 短期看不到结果，要不要放弃？外界都在唱衰，我还坚持吗？ |
| 12 | 风险控制 | 最坏情况怎么办？要不要留退路、留多少？ |

---

## 工作流程（四步）

```
① 识别场景    ── 把用户的问题映射到 12 个场景中的 1–3 个，复述确认
② 检索卡片    ── 按场景查「场景索引」，取 2–4 张方法卡
③ 结构化分析  ── 逐卡对答：方法论内核 / 决策算法 / 适用条件 / 误用警示
④ 输出建议    ── 五段式固定结构：主要矛盾·力量对比·时机判断·行动顺序·底线退路
```

**关键约束**（写在 `SKILL.md` 里，防止输出注水）：

- 只允许引用 `references/cards/` 中的卡片内容，**不臆造毛选原文**
- 取卡有上限（2–4 张，不可逆决策强制加 1 张风险控制卡，总数不超 5 张）
- 每条建议都必须由第 ③ 步的分析支撑，**不允许出现卡片方法之外的空泛套话**
- 信息不足时，把"缺什么信息、建议如何去补"写进「行动顺序」的第一步

## 输出样例

```markdown
## 决策建议

**主要矛盾**：当前决策中最关键的那个问题/冲突是什么（一句话，说明判断依据）。

**力量对比**：己方与对手/困难之间的资源、信息、时间对比；处于优势还是均势还是劣势。

**时机判断**：现在动还是等；判断依据是什么；等什么信号。

**行动顺序**：第一步做什么、第二步做什么（具体、可执行，注明每步的验证点）。

**底线与退路**：不可突破的底线是什么；失败后的退路是什么；什么情况触发撤退/转向。

**引用方法卡**：列出本次用到的素材卡名（篇目 + 场景标签）。
```

### 卡片格式

每张卡含四段固定结构 + frontmatter：

```markdown
---
篇目: 中国社会各阶级的分析
卷: 第一卷
年份: 1925
决策场景: 力量配置|矛盾分析|认知判断
一号线索: 先分清谁是朋友、谁是敌人，再决定把资源投向哪里。
金句: 谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。
---

## 方法论内核
## 决策算法        （3–7 步有序列表）
## 适用条件
## 误用警示
```

### 索引与卡片库的分工

| | 内容 | 作用 |
|---|---|---|
| `references/场景索引.md` | 68 张卡 | **快速入口**：每场景精选 5–6 张，★ 为首选 |
| `references/cards/` | 166 张卡 | **全量备选池**：索引里没有的卡，可按篇目名取用 |

卡片可以在多个场景下复用（frontmatter 的 `决策场景` 允许 1–3 个标签）。

---

## 校验

卡片必须符合《素材卡契约 v1》。随时运行：

```bash
python scripts/check_cards.py references/cards
```

校验规则：

| # | 规则 |
|---|---|
| 1 | frontmatter 六个字段齐全且非空（篇目 / 卷 / 年份 / 决策场景 / 一号线索 / 金句） |
| 2 | 决策场景 1–3 个，用 `\|` 分隔，且必须是 12 个规定标签之一 |
| 3 | 年份为纯数字 |
| 4 | 正文四小节齐全（方法论内核 / 决策算法 / 适用条件 / 误用警示） |
| 5 | 决策算法为 3–7 步**有序**列表 |
| 6 | 正文字数 300–800 汉字 |

全部通过时退出码为 `0`，存在不合格卡时为 `1`。

## 怎么用

### 作为 DSH / Claude Skill

把本仓库放到 skills 目录，目录名与 `SKILL.md` 的 `name` 保持一致：

```
<skills-dir>/maoxuan-decision/
```

然后即可通过自然语言触发（描述你面临的决策），或显式调用 `/maoxuan-decision`。

### 手动使用

`SKILL.md` 是自包含的流程说明。任何能读文件的 LLM 都能按它执行：
读 `SKILL.md` → 按第②步查 `references/场景索引.md` → 读对应卡片 → 按第③④步输出。

---

## 关于素材与引用

- **本仓库不含《毛泽东选集》原文。** 方法卡是对原著决策方法的**提炼与再表述**，
  不是原文摘录；卡片正文字数被契约限制在 300–800 字。
- 卡片 frontmatter 的 `金句` 字段为**原文引用**，已在卡片内注明篇目出处，
  用于说明该方法论的来源。
- 原著著作权归相应权利人所有。使用者应自行遵守所在地区的著作权法规。
